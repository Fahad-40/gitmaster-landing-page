Git vs. GitHub? +

Git is the core local engine—the version control software installed on your machine. GitHub is the cloud infrastructure that hosts Git repositories, enabling asynchronous collaboration, code review, and CI/CD pipelines.

Anatomy of a merge conflict? +

Conflicts arise when divergent branches mutate the exact same line of code, or when a file is deleted in one branch but modified in another. Git halts the automated merge process, demanding human intervention to dictate the final state.

Why branch locally? +

Directly manipulating the main production branch is perilous. Branching creates an isolated environment, ensuring the primary timeline remains stable while you engineer, test, and break features independently.
